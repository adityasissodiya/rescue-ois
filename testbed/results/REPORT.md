# AAS succession testbed: results

Generated by `python -m aas_testbed report` from the CSVs in this directory. Every number is a median over seeds unless the column says otherwise; `-` means the event never happened (for example, no takeover). Times are seconds after the partition begins. Defaults: L = 90 s, T = 300 s, T' = 240 s, outage 1200 s, operator and C react after 120 s of silence, a voice call takes 60 s, one decision per minute per commander, heartbeats and gossip every 2 s, eps = 0.2 s, settlement rule `closing`. FINDINGS.md (one directory up) interprets them. Code commit: `705c1874cae335390bb81a4d1b734caffd2f4dfa` (clean).
