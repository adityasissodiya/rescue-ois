# Design Previews

Static HTML pages from the project's first design pass, when the prototype's
architecture was called Tiered Sync: colour, spacing and type tokens, and sample
buttons, badges, cards and status indicators for the paper and the tablet UI. Open any
file in a browser.

Not maintained, and not part of any evaluation. The click-through tablet mock-up from
the same design pass is in [`../ui_kits/tablet/`](../ui_kits/tablet/README.md).
