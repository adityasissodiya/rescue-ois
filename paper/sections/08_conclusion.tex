\section{Conclusion}

This paper presents an offline-first incident-information architecture for rescue-service operations over intermittently connected mesh networks. The central design move is a tiered synchronization model with one command-side incident writer, forward-only field edits, and durable local caches at every tier. The expected contribution is not only the architecture itself, but also a clear argument for why this constrained consistency model is preferable to multi-writer approaches in a safety-critical command hierarchy.

Future work should address protocol verification, multi-incident scaling, tighter failover procedures for command promotion, and integration with narrower-band fallback communication channels.
