\section{Conclusion}

This paper presented authority-aligned linearization for rescue-service incident
information under intermittent edge connectivity. The protocol places
authority-bearing incident events at one serialization point: the node that
holds current operational command authority. Other state uses weaker contracts
for reference data, responder observations, artifacts, audit, and forwarding.

The prototype measures selected service paths. The abstract model checks the
promotion/fencing boundary. Together, they support the architecture's
consistency boundary under the stated assumptions.

The results do not validate a completed public-safety deployment. Remaining work
is to implement durable service-level epochs, add crash-boundary and Android
end-to-end tests, run physical mesh or field trials, and compare more directly
with emergency consensus and CRDT-based systems.
