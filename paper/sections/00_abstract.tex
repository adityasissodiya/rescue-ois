Edge applications spanning vehicle nodes, field tablets, and intermittent wide-area links need synchronization protocols that remain useful during partitions without obscuring which node has authority to commit safety-relevant state. We present a domain-specific, authority-aware, offline-first architecture for rescue-service incident operations. The design composes a regional core, vehicle edge nodes, durable outboxes, an append-only command-side journal, and bounded manual promotion: master data flows outward, responder submissions flow forward, and one command vehicle sequences authority-bearing incident events. The architecture deliberately chooses a different point in the design space from consensus-based state-machine replication, multi-primary replication, and CRDT-style merge. We evaluate a prototype in Docker Compose emulation across bootstrap, field-edit propagation, WAN-recovery, throughput, duplicate-replay, and selected Raft comparison scenarios. The emulation does not exercise the target Rajant mesh, WireGuard overlay, mTLS termination, or Android tablet path. Bounded TLA+ model checking and Hypothesis tests validate the single-writer and promotion invariants in an abstract model. The results show the trade-off made by the design: responder and WAN partitions need not block command-local progress, but command promotion requires explicit fencing and does not provide automatic failover.
