\section{Implementation}

The system is implemented as a set of containerized microservices (core and edge tiers) and a native Android application (tablet tier). All Python services target Python~3.12 and use FastAPI with Pydantic models, asyncpg for database access, and uvicorn as the ASGI server. Each service exposes a \texttt{GET /health} endpoint. Database schemas are managed through numbered, forward-only plain SQL migrations. Infrastructure is provisioned with Ansible playbooks and role-based templates for PostgreSQL, Martin, Nginx, and WireGuard.

The core tier comprises four Python microservices behind an Nginx reverse proxy. The \texttt{sync-api} serves baseline synchronization endpoints and incident bootstrap bundles. The \texttt{publisher} stages geodata through validation, promotes it to master tables, builds PMTiles via tippecanoe, bundles attachments into \texttt{tar.zst} archives, and atomically swaps signed manifests into a publication directory. The \texttt{feed-importer} ingests external data from four Swedish authorities. The \texttt{audit-api} provides batch ingest and query for forwarded audit events.

Each edge node runs a Docker Compose stack with PostgreSQL, Martin, Nginx, and three application services. The \texttt{ops-api} is the tablet-facing interface: it serves incident bootstraps, accepts field edits, proxies tiles, and streams attachment files. The \texttt{syncd} daemon implements four synchronization flows: pulling master data from core (Flow~1), pushing outbox entries from responder to command (Flow~4), accepting and sequencing events on the command node (Flow~4, server side), and forwarding the incident journal to core (Flow~5). The \texttt{audit-forwarder} batches local audit events and posts them to the core audit endpoint with exponential backoff on transient failures.

The tablet application is a single-activity Kotlin Android app. It uses Retrofit for HTTPS communication with the local vehicle \texttt{ops-api}, Room for local structured data, and MapLibre Native for offline map rendering from locally cached PMTiles. A \texttt{SyncManager} orchestrates baseline bootstrap, field edit submission with idempotency keys, and incremental event polling. The application enforces \texttt{usesCleartextTraffic=false} and disables backup.

Authentication follows a layered model. WireGuard provides network-level encryption between vehicles and core. Nginx terminates mTLS and extracts client certificate subjects, which are passed as headers to backend services. Tablets authenticate to their local vehicle via mTLS with certificates distributed through Knox Manage MDM. No parallel identity system is introduced; the deployment consumes the authority's existing organizational CA and IdP.
