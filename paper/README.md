# AAS paper, TCPS manuscript (working draft)

The journal manuscript for ACM Transactions on Cyber-Physical Systems, steered from the
WONS conference draft, which is kept as the tag `wons-draft` until the supervisors sign
off the system model. `TCPS_PLAN.md` says what changes and why, which decisions the
supervisors need to make, and what evidence is still missing. The code and the testbed
behind the manuscript are in this repository, one directory up.

**Status:** a working draft, not for submission. Text in orange brackets, written with
`\pending{}`, marks open points or planned work, not results.

## Layout

| Path | Contents |
| --- | --- |
| `main.tex` | Preamble (`acmart`, `acmsmall`) and the order of the sections |
| `sections/` | The manuscript's sections |
| `figures/` | Figures; `figures/README.md` says which ones the manuscript includes |
| `data/testbed_macros.tex`, `tables/tab_policy_costs.tex`, `tables/tab_faults.tex` | Testbed numbers and table rows, generated by `python -m aas_testbed latex` in `../testbed/`; do not edit |
| `data/TESTBED_TRACE.md` | Every testbed number, traced to its CSV, filter and statistic |
| `tables/`, `data/`, `scripts/` | The prototype's datasets and generators, carried over from the WONS draft |
| `model/` | The scenario and system model document, built on its own |
| `TRACEABILITY.md` | The prototype's numbers, traced to their datasets (from the WONS draft) |
| `refs.bib` | The bibliography |

## Building

`BUILDING.md` has the details. From this directory: with MiKTeX in PowerShell,
`.\build.ps1`; with TeX Live, `latexmk -pdf -outdir=build main.tex`. The PDF is
`build/main.pdf`. The LaTeX Workshop settings in `.vscode/` apply when VS Code opens this
directory, not the repository root, as its folder.
